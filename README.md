# Study02_ToDoList

하루 10~20개의 할 일을 관리하는 개인용 할 일 관리 웹 앱입니다.
HTML 파일 하나를 브라우저로 열면 바로 쓸 수 있고, 새로고침해도 데이터가 남습니다.

> **현재 상태:** 기획 단계입니다. PRD와 설계 명세를 작성했고, 구현은 아직 시작하지 않았습니다.

## 문서

- [PRD](docs/superpowers/specs/2026-10-02-todo-app-design.md)
  - 목표와 범위, 하루 사용 흐름, 기능 요구사항(F-1 ~ F-9)
  - 데이터 모델, 화면 설계, 내부 동작, 기술 제약
  - 예외 처리, 완료 기준, 다음 버전 후보

## 주요 기능 (예정)

- 할 일 추가 / 수정 / 삭제
- 완료 체크
- 카테고리 분류: 업무 / 개인 / 공부
- 카테고리 필터와 진행률 표시
- 날짜별 목록, 지난 날짜의 미완료 항목을 오늘로 옮기기
- 브라우저 localStorage에 자동 저장

## 기술

- 순수 JavaScript, HTML, CSS
- 외부 라이브러리와 빌드 도구 없음
- `index.html` 단일 파일

## 실행 방법 (구현 후)

`index.html`을 브라우저로 열면 됩니다. 인터넷 연결이나 서버가 필요 없습니다.

## 작업 방식

[Superpowers](https://github.com/obra/superpowers)의 `brainstorming` 스킬로 요구사항을 정리하고 설계를 확정했습니다.
